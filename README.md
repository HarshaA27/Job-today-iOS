# Job Today - iOS App

A SwiftUI-based field technician job management application.

## Features

- View today's assigned jobs
- Job list with customer details, address, schedule and status
- Job detail screen
- Mark jobs as completed
- Filter pending jobs
- Local JSON data loading

## Tech Stack

- Swift
- SwiftUI
- MVVM Architecture
- JSON Data Handling

## Requirements

- macOS
- Xcode
- iOS Simulator

## Run the App

1. Clone the repository
2. Open Job today.xcodeproj in Xcode
3. Select iPhone Simulator
4. Press Run (⌘ + R)
